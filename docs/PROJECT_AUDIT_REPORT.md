## ⚠️ 技术债务与风险

### 高优先级问题 🔴

#### 1. PowerSync API兼容性问题

**问题描述**:  
PowerSync包要求Dart SDK >=3.10.0，但Flutter 3.27.1使用Dart 3.6.0，导致API不兼容。

**影响范围**:  
- 同步功能在v0.3.2临时禁用
- 同步UI组件已移除
- 同步服务器代码保留但未集成

**解决方案**:
```dart
// v0.3.2临时方案
// packages/sync/lib/sync.dart - 已禁用
// apps/mobile/pubspec.yaml - 已注释依赖
```

**修复路径**:
1. 等待Flutter升级到Dart 3.10+
2. 或使用PowerSync旧版本兼容层
3. 预计v0.3.250+版本修复

#### 2. drift_flutter Isolate Bug

**问题描述**:  
drift_flutter 0.2.7版本的`isolateDebugLog`存在bug，导致后台isolate数据库访问失败。

**影响范围**:  
- 预算检查后台任务
- 周期性交易生成
- 后台同步服务

**临时方案**:
```yaml
# apps/mobile/pubspec.yaml
dependencies:
  drift_flutter: 0.2.6  # Pin to 0.2.6, avoid 0.2.7
```

**已修复版本**: v0.3.227

### 中优先级问题 🟡

#### 3. CI测试环境配置

**问题描述**:  
Widget测试需要显示服务器，CI环境中无法直接运行。

**当前方案**:
```yaml
# .github/workflows/test.yml
- name: Run tests
  run: xvfb-run melos run test
```

**优化建议**:
- ✅ 已配置xvfb-run
- ⏳ 考虑使用golden_test
- ⏳ 增加集成测试

已进行14次Schema迁移，迁移路径较长，存在潜在风险。
